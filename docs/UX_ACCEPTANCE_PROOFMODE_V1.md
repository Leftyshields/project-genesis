# ProofMode Engineering Copilot v1: UX interaction acceptance criteria (from UX agent, 2026-10-22)
Laws: Doherty threshold, Hick, Tesler, Jakob, Gestalt proximity/similarity, peak end.
1 Prompt panel: VS Code side panel, opens on test failure or "Debug this" command; never modal, never steal focus while typing. Visible within 200ms, cursor in diagnosis field. Four fields one screen: Diagnosis required multiline autogrow; Constraints, Likely failure, Proving test optional one line expanding. Placeholders are short questions ("What do you think is wrong?"), no char counters. Tab between fields, Cmd/Ctrl+Enter submits. Submit disabled until diagnosis has text, muted hint not red error. Prefill failing test name and top error line read only above fields. Draft saved locally every keystroke, restored on reopen.
2 Skip: text link "Skip" next to Submit, same size/weight, not red, no menu, no confirm. Esc skips. Recorded "skipped", never counts toward accuracy, no streak/loss copy. "Show advice" still available after skip.
3 Comparison: replaces prompt panel after Submit; skeleton while loading. Two columns "Your diagnosis" left, "AI advice" right; stack under 480px with engineer on top. Above columns three groups: "You caught" (green, first), "You both saw" (stone), "Worth a look" (amber); labels+icons never color alone. Copy from either column; each column collapsible.
4 Self mark: only after fix (failing test passes or "Mark diagnosis" command). Three equal segmented buttons Matched/Partial/Missed, click or keys 1/2/3. Optional one line note. Toast "Saved to your record", no interstitial. Editable 24h. Dismissed waits quietly, no nagging/badges.
5 Record view: command "ProofMode: My record". Top to bottom: 30 day accuracy headline with count ("18 of 25 matched"); weekly accuracy sparkline; "Top blind spots" exactly 3 chips with counts opening examples; recent sessions list. Skipped muted, excluded. Empty state "Your record starts after your first diagnosis." No fake data. "Stored only on this machine" line and Clear record action with confirm.
6 General: no dashes in any copy; no telemetry leaves the machine (local only); full keyboard support; follow VS Code theme dark and light.
Sign off: screenshots of each of five states in dark and light.
